# Tic Tac Toe

A modern neon-themed Tic Tac Toe game developed using HTML, CSS, and JavaScript. The game features both 2-player mode and AI bot mode with smooth animations, responsive design, score tracking, win and draw detection, and a glowing cyberpunk-inspired user interface.

## Features

* 2-player gameplay mode
* AI bot mode
* Win and draw detection system
* Restart/play again functionality
* Score tracking
* Neon dark theme UI
* Responsive layout for desktop and mobile
* Smooth animations and interactive effects

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Developed Using

* Antigravity AI Assistant
* Visual Studio Code / Antigravity IDE

## Objective

* The objective of the game is to place three matching symbols in a row, column, or diagonal before the opponent or AI bot while providing an interactive and 
* visually appealing gameplay experience.
